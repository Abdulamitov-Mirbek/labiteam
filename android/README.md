# Сигнал.kg — Android-замер (APK)

Нативное приложение: читает силу сигнала (**dBm / RSRP**) модема телефона и отправляет её
с GPS-точкой оператору — `POST /api/measurements` на сервер Сигнал.kg. Веб-приложение dBm
прочитать не может (браузер не отдаёт уровень сигнала), поэтому это отдельный `.apk`.

## Как получить APK (без Android Studio)

Собирается в GitHub Actions. После пуша в `main`:

1. GitHub → вкладка **Actions** → workflow **Android APK** → последний запуск.
2. Внизу, в разделе **Artifacts**, скачайте **signalkg-meter-apk** (это zip с `app-debug.apk`).
3. Распакуйте — внутри `app-debug.apk`.

Запустить сборку вручную можно кнопкой **Run workflow** (workflow_dispatch).

## Установка на телефон

1. Перекиньте `app-debug.apk` на Android (кабель, Telegram, почта).
2. Откройте файл → разрешите «Установка из этого источника» (это debug-сборка, не из Play Store).
3. При первом замере дайте разрешения на **геолокацию** и **телефон**.

## Как пользоваться

1. В поле «Адрес сервера» — `https://tolkun.online` (после выпуска HTTPS). Для теста можно
   указать любой адрес сервера Сигнал.kg, включая временный туннель.
2. Нажмите **«Замерить и отправить»**. Приложение определит место по GPS, прочитает dBm и сеть
   (2G/3G/4G/5G) и отправит замер. Он появится у оператора во вкладке «Замеры» и на карте.

Замеры вне Бишкека сервер не принимает (код 422); лимит — 20 замеров в минуту с одного адреса.

## Сборка локально (если есть Android SDK)

```bash
cd android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Параметры: `minSdk 29` (Android 10+), `compileSdk 34`, Gradle 8.7, AGP 8.5.2, JDK 17, без
сторонних зависимостей. Это **debug**-сборка для раздачи внутри команды; для публикации в
Play Store нужен релизный подписанный build — отдельный шаг.
