# Сигнал.kg — ТЗ 7 «Карта покрытия»

Карта качества мобильной связи Бишкека. Как в 2ГИС есть слой «Пробки», здесь — слой «Связь».

- **Ядро** по замерам строит сетку 200 × 200 м, находит слабые зоны и выбирает две площадки
  для новых базовых станций. Это ответ на ТЗ: `result.json` и HTML-карта.
- **Панель оператора** — та же карта плюс режим «Что если», игра «Поставь вышки сам»
  и жалобы жителей в реальном времени.
- **Chrome-плагин** показывает качество связи прямо в объявлении о квартире на house.kg и
  lalafo.kg. Кнопка «Здесь нет связи» отправляет жалобу на панель оператора.

## 1. Ядро — ответ для жюри

Чистый Python 3.11+, сторонние библиотеки не нужны.

```bash
python main.py                         # то же, что python -m covermap
python main.py --measurements hidden.csv --towers towers.csv --candidates candidates.csv
```

По умолчанию данные берутся из `data/07_coverage/`, результат пишется в `out/`:

| Файл | Содержимое |
|---|---|
| `out/result.json` | `worst_cells`, `best_candidates`, `dropped_rows`, `covered_weak_cells` |
| `out/map.html` | карта покрытия — открыть в браузере, сервер не нужен |
| `out/report.json` | сводка: причины отбрасывания строк, жадный алгоритм против перебора, день/ночь |

Ключи: `--data КАТАЛОГ` (все четыре файла сразу), `--measurements`, `--towers`, `--candidates`,
`--bounds`, `--out`, `--dgis-key` (или переменная `DGIS_KEY`).

На открытых данных `result.json` совпадает с `expected.json` полностью: отброшено 200 строк,
худшие квадраты `X006_Y013`, `X005_Y013`, `X006_Y012`, площадки `C09` + `C14`, покрыто 111
красных квадратов.

### Как выполнены обязательные пункты

Правила взяты из ТЗ и `CLARIFICATIONS_RU.md`, раздел 7.

1. **Очистка.** Строка отбрасывается, если она пустая, в ней не хватает полей, значения не
   являются конечными числами, время не в ISO 8601, RSRP вне −140…−44 дБм, координаты вне
   района (границы включены) или это дубль. Дубли ищутся по всем четырём полям, числа
   сравниваются как числа (`-98.2` и `-98.20` — одно значение). Разбивка по причинам — в
   `report.json` и на панели.
2. **Сетка 200 × 200 м.** Локальная модель из уточнений: `x = R·cos(lat0)·rad(lon − lon0)`,
   `y = R·rad(lat − lat0)`, клетка `(floor(x/200), floor(y/200))`, ID `X{ix:03d}_Y{iy:03d}`.
   Медиана RSRP по клетке; клетки с менее чем 5 замерами не учитываются.
3. **Цвета.** Зелёный — медиана ≥ −90, жёлтый — от −105 до −90, красный — < −105.
4. **Топ-3 худших квадрата.** По медиане, при равенстве — по `cell_id`.
5. **Две площадки.** Допустима площадка не ближе 500 м к каждой существующей БС. Площадка
   покрывает красный квадрат, если до его центра не больше 1000 м (гаверсинус,
   R = 6 371 000 м). Полный перебор пар допустимых площадок, максимум объединения без
   двойного учёта; при равенстве — лексикографически наименьшая пара.

### Бонусы

- **Жадный алгоритм против перебора.** Жадный выбирает `C16` + `C17` (108 квадратов) и
  проигрывает перебору (`C09` + `C14`, 111): он берёт лучшую одиночную площадку и уже не
  пересматривает её. Время обоих показано на панели. Перебор проверяет 120 пар допустимых
  площадок из 190 возможных: 4 площадки стоят ближе 500 м к БС.
- **День и ночь.** Ночь — 22:00–06:00 местного времени (в ТЗ не задано, выбрано нами).
  Отдельные слои на карте и сравнение в сводке.
- **Тепловая карта** слабого сигнала — отдельный слой.

## 2. Сервер и панель оператора

```bash
pip install -r requirements.txt
DGIS_KEY=ваш-ключ python -m server        # http://127.0.0.1:8000
```

Панель: <http://127.0.0.1:8000/>. Документация API: <http://127.0.0.1:8000/api/docs>.

| Запрос | Что делает |
|---|---|
| `GET /api/signal?lat=&lon=` | качество связи в точке: цвет, медиана, день/ночь, расстояние до слабой зоны. `400` — не числа, `422` — вне района |
| `GET /api/listing?url=` (или `?text=`) | связь в доме из объявления house.kg или lalafo.kg — для «Поделиться» на телефоне. `200` — `{url, site, title, lat, lon, in_area, signal}`; `400` — не ссылка на объявление; `404` — объявление снято; `422` — в объявлении нет точного адреса; `429` — больше 20 проверок в минуту с IP; `502` — сайт не ответил |
| `GET /api/cells` | все квадраты с медианой и цветом |
| `GET /api/result` | `result.json` |
| `POST /api/complaints {lat, lon, source, site}` | жалоба «Здесь нет связи». `201`; `400` — формат; `413` — тело больше 1 КБ; `422` — вне района; `429` — больше 5 жалоб в минуту с IP |
| `GET /api/complaints?after=ID` | жалобы новее ID и число отклонённых лимитом — панель опрашивает раз в 3 секунды |

Панель в светлом стиле LABI: четыре вкладки — «Карта», «Жалобы», «Плагин», «Данные».
Та же страница без сервера — `out/map.html` (без живых жалоб). Шрифты Inter и JetBrains Mono
встроены в страницу, поэтому без интернета пропадает только подложка карты.

На вкладке «Карта»:

- **Худшие квадраты** — клик по строке перелетает к квадрату.
- **«Что если»** — клик по площадке рисует круг 1 км и подсвечивает красные квадраты, которые
  она закроет; можно выбрать две и увидеть их общее покрытие и пересечение. Клик по серой
  площадке объясняет, почему она недопустима: «C01: 0 м до БС B01, нужно не меньше 500 м».
- **«Поставь вышки сам»** — ответ алгоритма скрыт. Выберите две площадки и получите очки, затем
  «Ответ алгоритма» покажет лучшую пару и разницу.
- **Жалобы жителей** появляются на карте сами, новая жалоба мигает, и карта сдвигается к ней.

На вкладке «Жалобы» — таблица жалоб с сайтом объявления и статусом квадрата («Закроет новая БС»,
«Слабая зона»), число отклонённых лимитом и квадрат, на который жалуются чаще всего.
«Данные» — источники, причины отбрасывания строк, жадный алгоритм против перебора, день/ночь
и `result.json`.

Настройки сервера: `COVERMAP_DATA` — каталог с данными, `DGIS_KEY` — ключ 2ГИС,
`COMPLAINTS_FILE` — файл жалоб (по умолчанию `var/complaints.jsonl`), `ALLOWED_ORIGINS` —
источники для CORS.

## 3. Приложение для жителей (PWA)

Сайт, который ставится на главный экран и открывается как отдельная программа: своя иконка,
без адресной строки, работает без сети.

- Адрес: <http://127.0.0.1:8000/app/>; `…/app/?demo=1` — демо-точка (Раззакова / Боконбаева)
  только для этой страницы, удобно для защиты; настройка не запоминается.
- «Связь здесь» — по геолокации показывает медиану сигнала в вашем квадрате 200 × 200 м,
  днём и ночью, и слабую зону рядом.
- «Здесь нет связи» — жалоба с координатами (`source: "app"`) сразу появляется на панели.
  Без сети жалобы ждут в очереди на телефоне и уходят сами, когда сеть появится.
- **Квартира из объявления — «Поделиться» → Сигнал.kg.** Плагин на телефоне не работает
  (мобильный Chrome не поддерживает расширения, а объявления смотрят в приложениях house.kg и
  lalafo), поэтому на Android приложение встаёт в меню «Поделиться» (`share_target` в манифесте).
  Сервер сам загружает объявление (`GET /api/listing`) и показывает связь в этом доме с кнопкой
  «В этом доме нет связи» — жалоба приходит на панель с сайтом объявления.
  Надёжность: сервер ходит только на house.kg и lalafo.kg (и по редиректам тоже), таймаут 8 с,
  страница не больше 5 МБ, ответы кешируются на 10 минут, ошибки сайта не кешируются.
  Точку «Бишкек по умолчанию», которую lalafo ставит без адреса (~10 % объявлений), не
  принимаем — иначе показали бы связь чужого дома. Снятое объявление house.kg (редирект на
  главную) — «объявление не найдено». Без сети ссылка ждёт и проверяется сама, когда сеть появится.
- Установка: Chrome → меню ⋮ → «Установить приложение»; iPhone → «Поделиться» →
  «На экран „Домой“». Пункт «Сигнал.kg» в меню «Поделиться» появляется только на Android и
  только после установки. Панель оператора тоже ставится как программа — кнопка «Установить панель».

С телефона нужен **HTTPS**: браузер даёт установку, «Поделиться» и геолокацию только по HTTPS
или на localhost, а по `http://<IP компьютера>:8000/app/` GPS не работает. Проще всего —
туннель с настоящим сертификатом:

```bash
python -m server
cloudflared tunnel --url http://127.0.0.1:8000    # выдаст https://….trycloudflare.com
```

Для постоянной ссылки нужен хостинг или именованный туннель со своим доменом.

Браузер не даёт сайтам читать уровень сигнала телефона (RSRP), поэтому приложение показывает
данные карты, а не меряет сигнал само.

## 4. Chrome-плагин

Установка: `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное
расширение» → папка `extension/`. Сервер должен быть запущен на `127.0.0.1:8000`
(адрес задан в `extension/background.js`).

Откройте объявление на house.kg (`/details/…`) или lalafo.kg (`…-id-NNN`): под заголовком
появится плашка, например

> 📶 Сигнал.kg Связь в этом доме: хорошая (−84) · ночью хуже (−97) · ⚠️ в 300 м слабая зона

Цвет полосы совпадает с цветом квадрата на карте. Координаты дома плагин берёт из самой
страницы: у house.kg — из JSON-LD `GeoCoordinates`, у lalafo — из `__NEXT_DATA__`, у
объекта с тем же id, что в адресе. При переходах внутри lalafo плашка обновляется.

Замеры покрывают только центр Бишкека (около 4 × 4 км). Для дома за пределами района плашка
так и пишет: «Дом вне района, где есть замеры связи».

## 5. Безопасность

- **Плагин.** Плашка собирается через `createElement` и `textContent`, без `innerHTML`, и живёт в
  закрытом Shadow DOM. Ключей и секретов в плагине нет. В API ходит только сервисный воркер;
  он принимает сообщения только от своих content scripts и проверяет, что координаты — числа.
  Доступ к сайтам ограничен house.kg и lalafo.kg. Сверх концепции нужен доступ к адресу API
  (`127.0.0.1:8000`), иначе воркер не сможет к нему обратиться.
- **API.** CORS разрешён только для house.kg и lalafo.kg. `lat`/`lon` проверяются как конечные
  числа внутри района. У жалоб — лимит 5 в минуту с IP (IP берётся из соединения, а не из
  `X-Forwarded-For`) и лимит размера тела 1 КБ. В жалобе хранятся только координаты, время,
  квадрат и источник — IP и другие персональные данные не сохраняются. Панель отдаётся
  с заголовками `X-Frame-Options: DENY` и `X-Content-Type-Options: nosniff`.
- **Данные.** CSV читается со строгой проверкой типов, без `eval`, с лимитом размера файла
  50 МБ. Строки из CSV (ID площадок и БС) выводятся на карту только как текст.

## 7. Сценарий демо (3 минуты)

1. **Боль (20 с).** «Снял квартиру, а связи нет. Оператор ставит вышки на глаз».
2. **Плагин (40 с).** Открыть объявление на house.kg в центре — плашка появляется сама.
3. **Жалоба (20 с).** Нажать «Здесь нет связи» — точка мигает на панели оператора.
4. **Панель (60 с).** Красные квадраты, топ-3 (клик — перелёт), 200 отброшенных строк по причинам.
5. **Игра (30 с).** Жюри ставит две вышки → «Ответ алгоритма» → жадный против перебора.
6. **Финал (10 с).** Сбор замеров с Android-телефонов и продажа решения операторам.
