# ТЗ 7. Карта покрытия

По замерам сигнала строит карту покрытия района Бишкека, находит слабые зоны и выбирает две
площадки для новых базовых станций. Чистый Python 3.11+, сторонние библиотеки не нужны.

## Запуск

```bash
python -m covermap
```

Команда читает данные из `data/07_coverage/` и пишет в `out/`:

| Файл | Содержимое |
|---|---|
| `out/result.json` | ответ для жюри: `worst_cells`, `best_candidates`, `dropped_rows`, `covered_weak_cells` |
| `out/map.html` | карта покрытия (Leaflet) — открыть в браузере |
| `out/report.json` | расширенная сводка: причины отбрасывания строк, сравнение алгоритмов, день/ночь |

Свои данные (например, скрытый набор):

```bash
python -m covermap --data путь/к/каталогу --out путь/к/результату
python -m covermap --measurements hidden.csv        # остальные файлы — из data/07_coverage
```

В каталоге `--data` ожидаются `measurements.csv`, `towers.csv`, `candidates.csv`, `bounds.json`;
каждый файл можно задать отдельно ключами `--measurements`, `--towers`, `--candidates`, `--bounds`.

На открытых данных `result.json` совпадает с эталоном `expected.json` полностью:
отброшено 200 строк, худшие квадраты `X006_Y013`, `X005_Y013`, `X006_Y012`, площадки
`C09` + `C14`, покрыто 111 красных квадратов.

## Как выполнены требования

Правила взяты из ТЗ и `CLARIFICATIONS_RU.md`, раздел 7.

1. **Очистка.** Строка отбрасывается, если она пустая, в ней не хватает полей, значения не
   являются конечными числами, время не в ISO 8601, RSRP вне −140…−44 дБм, координаты вне
   района (границы включены) либо это дубль. Дубли ищутся среди прошедших проверку строк по
   всем четырём полям; числа сравниваются как числа (`-98.2` и `-98.20` — одно значение).
   Число отброшенных строк идёт в `dropped_rows`, разбивка по причинам — в `report.json`
   и на карту.
2. **Сетка 200 × 200 м.** Локальная равнопромежуточная модель из уточнений:
   `x = R·cos(lat0)·rad(lon − lon0)`, `y = R·rad(lat − lat0)`, клетка `(floor(x/200), floor(y/200))`,
   идентификатор `X{ix:03d}_Y{iy:03d}`. По каждой клетке считается медиана RSRP; клетки
   с менее чем 5 замерами не учитываются.
3. **Цвета.** Зелёный — медиана ≥ −90, жёлтый — от −105 до −90, красный — < −105 (слабая зона).
4. **Топ-3 худших квадрата.** Сортировка по медиане, при равенстве — по `cell_id`.
5. **Две площадки.** Допустима площадка, от которой до каждой существующей БС не меньше 500 м.
   Площадка покрывает красный квадрат, если до его центра не больше 1000 м (гаверсинус,
   R = 6 371 000 м). Перебираются все пары допустимых площадок, выбирается пара с наибольшим
   объединением покрытых квадратов — без двойного учёта; при равенстве берётся
   лексикографически наименьшая пара ID.

## Бонусы

- **Жадный алгоритм и полный перебор.** Считаются оба. На открытых данных жадный выбор
  (`C16` + `C17`, 108 квадратов) проигрывает перебору (`C09` + `C14`, 111): он берёт лучшую
  одиночную площадку и уже не пересматривает её. В ответ идёт результат перебора.
- **День и ночь.** Замеры делятся по местному времени (ночь — 22:00–06:00), по каждой части
  строится своя сетка. На карте это отдельные слои, в сводке — число красных клеток днём и ночью.
- **Тепловая карта** слабого сигнала — отдельный слой на карте.

## Карта

`out/map.html` — один самодостаточный файл: Leaflet встроен внутрь, сервер не нужен. Без
интернета не подгружается только подложка, сетка и все слои остаются.

Подложка — карта 2ГИС; если её тайлы недоступны, карта сама переключается на Esri World
Street Map. Ключ API 2ГИС передаётся при генерации и в репозитории не хранится:

```bash
DGIS_KEY=ваш-ключ python -m covermap        # или: python -m covermap --dgis-key ваш-ключ
```

На карте: сетка квадратов трёх цветов, топ-3 худших квадрата (цифры 1–3), существующие БС и
их запретные зоны 500 м, все площадки-кандидаты, выбранная пара с радиусами 1 км, красные
квадраты под новым покрытием (тёмная рамка), слои «день» и «ночь», тепловая карта.
Слева — сводка по всем пунктам задания.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

47 тестов: каждая причина отбрасывания строк, границы диапазонов, сетка и гаверсинус, цвета,
сортировки и правила при равенстве, сравнение жадного алгоритма с перебором, сверка с
`expected.json`, запуск из командной строки и сообщения об ошибках.

## Структура

| Файл | Назначение |
|---|---|
| `covermap/geo.py` | сетка, перевод координат, гаверсинус |
| `covermap/cleaning.py` | чтение и очистка замеров |
| `covermap/analysis.py` | медианы по клеткам, цвета, худшие клетки, выбор площадок, день/ночь |
| `covermap/pipeline.py` | сборка результата и сводки |
| `covermap/render.py`, `covermap/template.html` | HTML-карта |
| `covermap/__main__.py` | запуск из командной строки |
| `covermap/vendor/` | Leaflet 1.9.4 и Leaflet.heat (встраиваются в карту) |
| `data/07_coverage/` | открытые данные организаторов |
| `out/` | результат на открытых данных |
